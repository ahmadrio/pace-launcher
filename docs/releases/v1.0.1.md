PACE Launcher 1.0.1: the emoji picker now has every emoji in Unicode 17.

**Requirements:** macOS 27 on Apple silicon.

## What's new
- **All 1,914 Unicode 17 emoji.** The picker used to miss 266 emoji made of several characters. Now it includes:
  - people by job and gender: 🧑‍💻 👩‍⚕️ 🤷‍♂️ 🏃‍♀️
  - families and couples: 👨‍👩‍👧 🧑‍🤝‍🧑 👩‍❤️‍👨
  - 😮‍💨 😵‍💫 ❤️‍🔥 🐈‍⬛ 🐦‍🔥 🍋‍🟩
  - keycaps 1️⃣ #️⃣, and ©️ ®️
  - 🏳️‍🌈 🏴‍☠️, and the flags of England, Scotland and Wales 🏴󠁧󠁢󠁥󠁮󠁧󠁿
- Each one appears right after the emoji it builds on, so 🤷 🤷‍♂️ 🤷‍♀️ sit together.
- **Skin tones for the new emoji.** ⌘T and ⌘⇧T work on them as well. Everyone in the emoji gets the same tone: 🧑‍💻 → 🧑🏽‍💻, 🧑‍🤝‍🧑 → 🧑🏽‍🤝‍🧑🏽. 👯 and 🤼 can now take a tone too, as Unicode 17 added one.
- Families keep their default look, because Unicode defines no skin tones for them.
- New search words: `programmer` finds 🧑‍💻 and `pride` finds 🏳️‍🌈.

## Install or update
1. Download `PACE-Launcher-1.0.1.dmg` and `PACE-Launcher-1.0.1.dmg.sha256` below.
2. Optional: check the download. In Terminal, in the folder holding both files (for example `cd ~/Downloads`), run `shasum -a 256 -c PACE-Launcher-1.0.1.dmg.sha256`; it should print `OK`.
3. Quit PACE Launcher, open the DMG, and drag PACE Launcher to Applications, replacing the old copy. Your settings, clipboard history, snippets and notes stay.
4. PACE Launcher is not notarized by Apple. Each new version must be approved once: open it, then go to **System Settings › Privacy & Security** and click **Open Anyway**. Permissions you already granted are kept.

The full guide is in [docs/INSTALL.md](https://github.com/ahmadrio/pace-launcher/blob/main/docs/INSTALL.md).

**Goal:** Quicklinks (URL templates opened from the launcher), locale-grouped calculator results, and the deferred tahap-6/5 minors.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-7-design.md`. Read it first, plus `HANDOFF.md` and the "Final: minor (deferred)" lines in `docs/superpowers/plans/2026-11-10-tahap-6-ledger.md`.

## Global Constraints
- **Toolchain:** `.macOS(.v27)`, Swift 6, CLT only. No `@State`, `#Preview`, SwiftData, XCTest, or external dependencies. Core imports no AppKit/SwiftUI.
- **Network:** DOT itself still makes only the exchange-rate request. Quicklinks hand URLs to `NSWorkspace`; DOT does not fetch them.
- **Logging:** never log queries, quicklink text or filled URLs above `.debug`. Quicklink names may be logged at `.info`.
- **Test isolation:**
  - UI checks use `DOTDataRootOverride` + `DOTiCloudRootOverride` → scratchpad folders (`scratchpad/t6/env.sh on|off`).
  - Snapshot and restore Pace's clipboard around any check that writes to it, and compare the hashes.
  - App back on real data after each UI check.
- **Keystrokes:** send them only through the focus guard (`scratchpad/t6/dotkeys.sh`, or `type.sh` to open and type). Never send Esc or ⌘W unguarded, and close Settings with the AX close button.
- **Opening URLs in UI checks:** use a quicklink pointing at a local file (`file:///…/t7.html`) or check what was requested, so no real website is opened during tests.
- **Workflow:** `make run` only. Commit per task, with messages ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **Typed text is fully encoded.** `a&b=c#d?e/f+g`, spaces, emoji and "Bahasa" text reach the URL encoded; `{query}` may appear twice. Test: Task 2 `` `query text is percent-encoded` ``.
2. **A plain word never triggers the inline row.** `g`, `g ` (no text), `gmail`, `gh` alone show no "Search …" row; `GH Dot` does. Test: Task 2 `` `the keyword needs a space and text` ``.
3. **settings.json stays loadable.** Missing `quicklinks` → defaults; `[]` stays empty; one malformed entry is skipped without dropping the rest or resetting other settings. Test: Task 2 `` `quicklinks load leniently` ``.
4. **Invalid URLs are refused and never opened.** No scheme, spaces, or garbage give the URL message. Test: Task 2 `` `urls need a scheme` ``.
5. **The copied calculator value stays ungrouped.** Test: Task 1 `` `copied results keep no grouping` ``.

### Task 2: Quicklink core

**Files:**
- Create: `Sources/DOTLauncherCore/Quicklinks/Quicklink.swift`
- Modify: `Sources/DOTLauncherCore/Settings/SettingsData.swift`
- Test: `Tests/DOTLauncherCoreTests/QuicklinkTests.swift`, `SettingsFileTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public struct Quicklink: Codable, Sendable, Equatable, Identifiable {
      public var id: UUID
      public var name: String
      public var keyword: String?        // nil or one word
      public var url: String             // template; "{query}" (any case) marks the text
      public init(id: UUID = UUID(), name: String, keyword: String?, url: String)
      /// Google "g" https://www.google.com/search?q={query}, YouTube "yt"
      /// https://www.youtube.com/results?search_query={query}, GitHub "gh" https://github.com/search?q={query},
      /// Google Maps "maps" https://www.google.com/maps/search/{query}; fixed UUIDs.
      public static let defaults: [Quicklink]
      public var takesQuery: Bool
      /// Every {query} replaced by `query` percent-encoded (unreserved characters only); nil when the
      /// result does not parse as a URL with a scheme.
      public func url(for query: String) -> URL?
  }
  public enum Quicklinks {
      /// "gh dot launcher" → (GitHub, "dot launcher"): an exact keyword (any case) of a link that takes
      /// a query, a space, then non-blank text (trimmed).
      public static func match(_ query: String, in links: [Quicklink]) -> (link: Quicklink, text: String)?
      /// The first problem with saving `draft` among `existing` (the draft's own id is ignored), or nil.
      public static func problem(with draft: Quicklink, existing: [Quicklink]) -> String?
  }
  // SettingsData: public var quicklinks: [Quicklink] = Quicklink.defaults
  //   missing key → defaults; malformed entries skipped; a wrong type → defaults (other settings kept)
  ```
  - Problem messages (in order):
    - "Add a name."
    - "A keyword is one word, without spaces."
    - "Another quicklink uses this keyword."
    - "Enter a full URL, such as https://example.com/search?q={query}."
  - An empty keyword (`""` or spaces) is treated as no keyword.

- [ ] **Step 1: Write the failing tests:**
  - `` `query text is percent-encoded` ``:
    - `Quicklink(name: "G", keyword: "g", url: "https://x.test/s?q={query}&again={QUERY}").url(for: "a&b=c#d?e/f+g h")?.absoluteString == "https://x.test/s?q=a%26b%3Dc%23d%3Fe%2Ff%2Bg%20h&again=a%26b%3Dc%23d%3Fe%2Ff%2Bg%20h"`
    - `"kopi ☕️"` → `"kopi%20%E2%98%95%EF%B8%8F"`
  - `` `links without a query open as they are` ``: `url(for: "ignored")` of `https://mail.google.com` is `https://mail.google.com`, and `takesQuery` is false.
  - `` `the keyword needs a space and text` ``: with the defaults, `match("gh dot launcher")` → GitHub + `"dot launcher"`, and `match("GH  Dot ")` → GitHub + `"Dot"`. `match("g")`, `match("g ")`, `match("gmail")`, `match("gh")` and `match("dot gh x")` are nil. A link without `{query}` never matches.
  - `` `urls need a scheme` ``: the URL problem for `"example.com/search?q={query}"`, `"https://exa mple.com"`, `""` and `"::"`; nil for `"obsidian://open?vault={query}"` and `"mailto:{query}"`.
  - `` `drafts are checked in order` ``: name empty → "Add a name."; keyword `"g h"` → spaces message; keyword `"G"` against the defaults → "Another quicklink uses this keyword."; editing Google itself with keyword `"g"` → nil.
  - `` `quicklinks load leniently` `` (SettingsFileTests):
    - `{}` → `Quicklink.defaults`
    - `{"quicklinks": []}` → `[]`
    - `{"quicklinks": [{"id": "<uuid>", "name": "A", "url": "https://a.test"}, {"name": 3}], "showMenuBarIcon": false}` → one link "A" and `showMenuBarIcon == false`
    - `{"quicklinks": "oops"}` → defaults
    - round-trip encode/decode keeps the list
- [ ] **Step 2: Run** `swift test --filter "QuicklinkTests|SettingsFileTests"`. Expected: compile failure, then stub failures.
- [ ] **Step 3: Implement.**
  - Allowed characters are `A–Z a–z 0–9 - . _ ~`.
  - Parse with `URL(string:encodingInvalidCharacters: false)`, because the lenient default would accept `https://exa mple.com`, and require a non-empty scheme.
  - Validation fills `{query}` with `test`.
  - Decode the array as `[Lossy<Quicklink>]` (a wrapper whose `init(from:)` keeps nil on failure).
- [ ] **Step 4: Run** `make test`. Expected: all pass.
- [ ] **Step 5: Commit** `Add quicklink model, URL filling and validation`.

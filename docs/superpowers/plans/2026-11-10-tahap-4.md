# Tahap 4 (AI Chat History, Clipboard Images + Preview + Pin/Delete, Shortcut Settings) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Saved, searchable, resumable AI chats; image clips with a preview pane and pin/delete in the panel; every global shortcut editable in Settings.

**Architecture:**
- Testable logic goes in `DOTLauncherCore`:
  - `Chat/`: `ChatStore`, `ChatTitle`, `SavedChatMessage`
  - `Clipboard/`: image kind, `ClipImage` (ImageIO conversion), image files in `ClipboardStore`, `ClipStats`
  - `Hotkeys/`: `ShortcutID`, `Shortcuts` (resolve, validate, gate), `KeyCombo.stringValue`
- The app target owns the glue:
  - `AIChatController` persistence and resume (`LanguageModelSession(transcript:)`)
  - the `.chatHistory` mode
  - image capture and paste
  - the preview pane
  - Settings › Shortcuts with a recorder
  - live hotkey re-registration

**Tech Stack:** Swift 6.4, SwiftPM, AppKit + SwiftUI, SQLite3, ImageIO, FoundationModels, Carbon hotkeys, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-4-design.md`. Read it first. `HANDOFF.md` describes the app, and `docs/superpowers/plans/2026-11-10-tahap-3-ledger.md` holds earlier rulings.

## Global Constraints

- **Toolchain**
  - `.macOS(.v27)`, Swift 6 mode, Command Line Tools only.
  - No `@State`: use `@Observable` + `@Bindable`.
  - No `#Preview`, no SwiftData, no XCTest, no external dependencies.
- **Isolation:** `DOTLauncherCore` imports no AppKit or SwiftUI. ImageIO and CoreGraphics are allowed. The app target is `defaultIsolation(MainActor.self)`.
- **Local only:** `chat.sqlite`, `clipboard.sqlite`, `launcher.sqlite` and `Clipboard Images/` always live in `AppPaths.localRoot`, never in iCloud, and are never part of the iCloud backup.
- **iCloud is opt-in:** with sync off, nothing reads or writes the iCloud folder.
- **Logging:** never log user content (chat text, clip text, image data) above `.debug`.
- **Panels:** panels stay non-activating.
- **Test isolation**
  - UI checks run with `DOTDataRootOverride` pointing at a scratchpad folder, never Pace's real data.
  - Snapshot Pace's clipboard (all types) before any check that writes to it, restore it after, and compare.
- **Workflow**
  - Run only via `make run`.
  - Verify UI with `osascript` System Events plus screenshots in the scratchpad.
  - Commit per task. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Copy:** user-facing strings are English, matching the existing UI.

## Review Focus

1. **Huge images.** A 40 MB TIFF screenshot must be skipped, not stored, and the panel must not stall. List rows use 128 px thumbnails, never the full PNG. Test: Task 3 `` `images over the size limit are refused` ``.
2. **Text-plus-image copies** (spreadsheet cells, rich web selections) stay text clips. Test: Task 3 `` `a copy with text and an image is not an image clip` ``.
3. **Image clips without their file** (restored from a backup, or a deleted file) show "Image unavailable" and refuse to paste, without crashing. Test: Task 3 `` `a missing image file reports no url` ``.
4. **Recorder input outside the key table** (numpad, ISO keys, modifier-only) is refused with a message, and the recorder keeps listening. Test: Task 6 `` `keys outside the table are refused` ``.
5. **A resumed chat longer than the model's context** shows the existing "This chat is too long" message and does not lose the saved history. Covered by Task 2 step 5 (UI) and Task 1 `` `appending again adds messages in order and moves the chat to the top` ``.

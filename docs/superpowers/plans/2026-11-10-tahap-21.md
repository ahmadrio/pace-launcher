# Tahap 21 (Rename to PACE Launcher) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename DOT Launcher to PACE Launcher everywhere (bundle, modules, strings, keys), and move Pace's data and settings on first launch.

**Architecture:**
- **Core:**
  - `Migration/LegacyMigration`: folder move (FileManager, testable with temp dirs) and defaults mapping (pure)
  - `ScriptMetadata`: accepts `@pace.`
- **App:** runs the migration at the start of `applicationDidFinishLaunching`, before anything reads `AppPaths`.
- **Mechanical rename:** directories, module names, the Makefile, the build script, Info.plist, and user-facing strings.

**Tech Stack:** Swift 6.4, SwiftPM, AppKit, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-21-design.md`.

## Global Constraints
- **No new permissions.** The existing ones must be granted again for the new bundle ID; Pace does that.
- **Never lose data.** Make a full backup of Pace's data and old defaults before the first real launch, and move the old app aside rather than deleting it.
- **iCloud Drive is untouched while sync is off.** This is Pace's case.
- UI checks use the test folders, with the scratchpad tools updated for the new process name, bundle ID and keys.

## Review Focus
1. **Never overwrite.** When both the old and the new folder exist, nothing moves. Test: Task 1 `` `an existing new folder is left alone` ``.
2. **Test hooks are not migrated.** Old override and dry-run keys are dropped. Test: Task 1 `` `old settings carry over without test hooks` ``.
3. **Old script headers keep working.** `@dot.title` and `@raycast.title` still parse, and `@pace.title` parses too. Test: Task 1.
4. **No user-facing "DOT" is left.** A grep of Sources and Resources for `DOT` finds only the legacy migration constants and the `@dot.` prefix. Test: Task 2 grep.
5. **Real data arrives intact.** The clip count, snippet and note files, and `settings.json` match the backup. Test: Task 3.

### Task 1: Core

**Files:**
- Create: `Sources/DOTLauncherCore/Migration/LegacyMigration.swift` (moved with the rename in Task 2)
- Modify: `Sources/DOTLauncherCore/Scripts/ScriptMetadata.swift`
- Test: `Tests/DOTLauncherCoreTests/LegacyMigrationTests.swift`, `ScriptMetadataTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public enum LegacyMigration {
      public enum FolderOutcome: Equatable, Sendable { case moved, nothingToMove, bothExist }
      public static func moveFolder(from old: URL, to new: URL, fileManager: FileManager = .default) throws -> FolderOutcome
      /// Old defaults → new: window frame names renamed, test hooks dropped.
      public static func defaults(from old: [String: Any]) -> [String: Any]
      public static let oldBundleID = "com.pace.DOTLauncher"
      public static let doneKey = "migratedFromDOTLauncher"
  }
  ```
- [ ] **Step 1: Write the failing tests:**
  - `` `the old folder moves to the new name` ``: a temp `old/` with `a.txt` and `sub/b.txt` → `.moved`; the new folder has both files, and the old one is gone.
  - `` `an existing new folder is left alone` ``: both exist → `.bothExist`, and both are unchanged.
  - `` `nothing to move` ``: the old folder is missing → `.nothingToMove`.
  - `` `old settings carry over without test hooks` ``:
    - Input: `["NSWindow Frame DOTNotesWindow": "f1", "NSWindow Frame DOTSettingsWindow": "f2", "syncEnabled": true, "extraScriptFolders": ["/x"], "DOTDataRootOverride": "/t", "DOTiCloudRootOverride": "/t", "DOTRatesURLOverride": "u", "DOTSystemCommandDryRun": true]`

  - `` `script headers in all three spellings` ``: `# @pace.title A`, `# @dot.title B` and `# @raycast.title C` each parse to their title, and `@pace.needsConfirmation true` works like `@dot.`.

### Task 2: Rename

- Modify: `Package.swift`, `Makefile`, `scripts/build-app.sh`, `Resources/Info.plist`, every Swift file (imports, strings, comments), `AppPaths`, `Log`, `AppDelegate` (run the migration)

- [ ] **Step 1: Rename** with `git mv`, then make the replacements in this order:
  1. `com.pace.DOTLauncher` → `io.github.ahmadrio.PACELauncher`, except the legacy constant.
  2. `DOTLauncherCoreTests` → `PACELauncherCoreTests`, then `DOTLauncherCore` → `PACELauncherCore`, then `DOTLauncher` → `PACELauncher`.
  3. Test keys `DOTDataRootOverride`, `DOTiCloudRootOverride`, `DOTRatesURLOverride` and `DOTSystemCommandDryRun` → `PACE…`; `DOT_SIGN_IDENTITY` → `PACE_SIGN_IDENTITY`.

  5. `"DOT Launcher"` → `"PACE Launcher"`, `"DOT Notes"` → `"PACE Notes"`, then the remaining word `DOT` → `PACE` in strings and comments.
  6. The script template and Settings copy use `@pace.title`.
  - Keep the legacy constants in `LegacyMigration` and the `@dot.` prefix.
- [ ] **Step 2: Wire the migration** first thing in `applicationDidFinishLaunching`, skipped when an override key is set:

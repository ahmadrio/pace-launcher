# Tahap 14 (Consistent "Press Again" Confirmations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One rule for Log Out, script-row, script-form and script-shortcut confirmations: the second press counts only while the prompt shows, and the prompt goes when the first press stops counting. Also "(not found)" titles for missing scripts.

**Architecture:**
- Core:
  - `PressConfirmation`: a public `window`
  - a clock that steps back ends the arm
- App:
  - `ConfirmationPrompt` (new) wraps `PressConfirmation` with show / is-shown / hide closures and the clearing Task
  - `HUDController` gains `currentText`, `hide()` and a `duration`
  - Log Out, `ScriptActions` (row, form, shortcut) use the prompt
  - `shortcut(for:)` titles missing scripts "<file> (not found)"

**Tech Stack:** Swift 6.4, SwiftPM, AppKit, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-14-design.md`.

## Global Constraints
- Same as tahap 13. No new permissions.
- UI checks use the test folders, the focus guards, clipboard snapshots, and `DOTSystemCommandDryRun`.
- Script runs use test scripts that only touch marker files in the scratchpad.

## Review Focus
1. **A stale first press never runs a script.** Script row: ↩, type a letter and delete it, ↩ → only the prompt, and no marker. Test: Task 2 UI check.
2. **The prompt and the arm end together, for all four prompts.** Footer, form message and HUD are gone after about 3 s. Test: Task 2 UI check (row and HUD), Task 1 `` `a clock that steps back ends the arm` ``.
3. **Form edits need a new confirmation.** ↩ → prompt, edit a value, ↩ → prompt again, no run. Test: Task 2 UI check.
4. **The global shortcut still confirms on a quick second press.** ⌃⌥⌘4 twice within 1 s runs the script once. Test: Task 2 UI check.
5. **Missing scripts are named as such.** The menu bar's All Shortcuts shows "gone.sh (not found)", and the script title is back once the file returns. Test: Task 2 UI check.

### Task 2: App

**Files:**
- Create: `Sources/DOTLauncher/UI/ConfirmationPrompt.swift`
- Modify:
  - `Sources/DOTLauncher/Scripts/HUDController.swift`
  - `Sources/DOTLauncher/Scripts/ScriptActions.swift`
  - `Sources/DOTLauncher/App/AppDelegate.swift` (Log Out, `runScriptShortcut`, `shortcut(for:)`)

**Interfaces:**
- Produces:
  ```swift
  final class ConfirmationPrompt {
      /// True when this press confirms `id`. Otherwise arms it and calls `show`;
      /// once the arm has ended, calls `hide` if `isShown()` is still true.
      func press(_ id: String, isShown: @escaping () -> Bool, show: () -> Void, hide: @escaping () -> Void) -> Bool
      func reset()
  }
  // HUDController
  private(set) var currentText: String?   // nil once hidden
  func show(_ text: String, isError: Bool, duration: TimeInterval = 2.2)
  func hide()
  ```

- [ ] **Step 1: Implement.**
  - **`ConfirmationPrompt.press`:**
    - Call `confirmation.press(id, at: .now, stillShown: isShown())`; return true when it confirms.
    - Otherwise call `show()`, then start a Task: sleep `window + 0.1` s, then loop every 0.2 s while `isArmed(id, .now)`, then `if isShown() { hide() }`.
  - **Log Out:** replaces `logOutConfirmation` and its Task.
  - **Script row:** `isShown` is `model.notice == prompt`; `hide` sets `model.notice = nil`.
  - **Form:**
    - `isShown` is `form.message == prompt && form.values == valuesWhenAsked`.
    - Record `valuesWhenAsked` when showing.
    - `hide` clears `form.message` when it is still the prompt.
  - **Shortcut:**
    - `runFromShortcut(_:comboText:showPanel:hud:)` takes the `HUDController` instead of `notify`.
    - `isShown` is `hud.currentText == prompt`.
    - `show` is `hud.show(prompt, isError: false, duration: window + 1)`.
    - `hide` is `hud.hide()`.
  - **Missing script titles:** `shortcut(for: .script)` returns `"\(id.title) (not found)"` when the file is missing.
- [ ] **Step 2: Run** `make test`. Expected: all pass.

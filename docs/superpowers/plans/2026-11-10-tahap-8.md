# Tahap 8 (Emoji Picker, Paste as Plain Text, Deferred Fixes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An emoji picker mode, "Paste as Plain Text" in Clipboard History, and the tahap-7 deferred minors.

**Architecture:**
- Core:
  - `Emoji/EmojiCatalog` (Unicode scalars + flags + a small table of popular names/keywords)
  - `CommandShortcut.searchEmoji`
  - `ClipItem.plainText`
  - lenient quicklink decoding and URL parsing
  - `SettingsFile` without escaped slashes
  - `ScriptFolderEvents` relevance filter
- App:
  - `.emoji` mode + "Search Emoji" command
  - the plain-text secondary action
  - folder watcher (missing folder, filtered paths)
  - quicklink form closes with Settings

**Tech Stack:** Swift 6.4, SwiftPM, AppKit + SwiftUI, CryptoKit, CoreServices FSEvents, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-8-design.md`. Read it first, plus `HANDOFF.md` and the "Final: minor (deferred)" lines in `docs/superpowers/plans/2026-11-10-tahap-7-ledger.md`.

## Global Constraints
- **Toolchain:** `.macOS(.v27)`, Swift 6, CLT only. No `@State`, `#Preview`, SwiftData, XCTest, or external dependencies. Core imports no AppKit/SwiftUI.
- **Logging:** never log queries, emoji chosen or clip text above `.debug`.
- **Test isolation:**
  - UI checks run on the scratch test folders (`scratchpad/t6/env.sh on|off`).
  - Keystrokes go through the focus guards (`dotkeys.sh`, `type.sh`, and `settype.sh` for Settings).
  - Snapshot and restore Pace's clipboard with matching hashes.
  - App back on real data after each UI check.
  - Use only TextEdit documents the check creates, and close them with `saving no`.
- **Workflow:** `make run` only. Commit per task, with messages ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **Text-default emoji render as emoji.** ❤, ☀ and ✔ carry U+FE0F, while ASCII digits, `#`, `©`, `®` and skin-tone modifiers are excluded. Test: Task 1 `` `the catalog has single emoji and flags only` ``.
2. **Popular names are findable in both languages.** `love`, `cinta`, `ketawa`, `thanks`, `jepang` find ❤️, ❤️, 😂, 🙏 and 🇯🇵. Test: Task 1 `` `popular emoji are found by everyday words` ``.
3. **Plain-text paste never touches history.** The stored clip and its representations are unchanged, and no new clip is added. Test: Task 3 UI check (count and hash of the row before and after).
4. **Hand-written quicklinks survive.** A missing `id` gives a stable id across loads; duplicate ids are split. Test: Task 4 `` `quicklinks without or with duplicate ids load` ``.
5. **The watcher ignores noise.** `.git`, deep paths, sibling folders and `/tmp/mainly` vs `/tmp/main` are not relevant. Test: Task 5 `` `only script-relevant paths trigger a reload` ``.

      public let keywords: [String]         // lowercased; from the popular table, and the Indonesian region name for flags

**Files:**
- Modify:
  - `Sources/DOTLauncherCore/Quicklinks/Quicklink.swift` (custom `init(from:)`, URL parsing)
  - `Sources/DOTLauncherCore/Settings/SettingsData.swift` (unique ids after decoding)

  - `Sources/DOTLauncher/Settings/SettingsWindowController.swift` (`windowWillClose` → `quicklinks.cancel()`)
- Test: `QuicklinkTests.swift`, `SettingsFileTests.swift`

**Interfaces:**
- Produces:
  - `Quicklink.init(from:)`: `id` = `decodeIfPresent ?? Quicklink.derivedID(name:url:)`.
  - `static func derivedID(name: String, url: String) -> UUID`: the first 16 bytes of SHA-256 of `name + "\n" + url`, with version 5 and variant bits set.
  - After decoding, `SettingsData` gives every repeated id after the first `derivedID(name: name, url: url + "#<index>")`.

- [ ] **Step 1: Write the failing tests:**
  - `` `quicklinks without or with duplicate ids load` ``:
    - `[{"name":"Wiki","url":"https://w.test/{query}"}]` decodes twice to the same non-nil id.
    - Two entries with the same id → different ids, and the first keeps its id.
    - A save and load round-trip keeps them.
  - `` `urls with non-ASCII letters or bars are accepted` ``:
    - `https://bücher.de/?q={query}` → `url(for: "a")?.host() == "xn--bcher-kva.de"`
    - `https://example.com/søk?q={query}` and `https://e.com/?a=b|c&q={query}` are accepted
    - `"https://exa mple.com"` and `"https://e.com/a b?q={query}"` are still refused (whitespace in the template)
  - `` `settings are written without escaped slashes` ``: the saved `settings.json` text contains `https://www.google.com/search` and no `\/`.
- [ ] **Step 2: Run** `swift test --filter "QuicklinkTests|SettingsFileTests"`. Expected: failures.
- [ ] **Step 3: Implement.** In `url(for:)`, return nil when the template contains whitespace, else parse the filled string with lenient `URL(string:)`, and require a scheme. The existing tests still pass.
- [ ] **Step 4: Run** `make test`. Expected: all pass.
- [ ] **Step 5: Commit** `Load hand-written quicklinks and accept international URLs`.

### Task 5: Script folder watching

**Files:**
- Create: `Sources/DOTLauncherCore/Scripts/ScriptFolderEvents.swift`
- Modify: `Sources/DOTLauncher/Scripts/ScriptFolderWatcher.swift`
- Test: `Tests/DOTLauncherCoreTests/ScriptShortcutTests.swift` (or a new file)

**Interfaces:**
- Produces:
  ```swift
  public enum ScriptFolderEvents {
      /// What to watch for `folders`: each existing folder, or the parent of a missing one (when the parent exists).
      public static func watchPaths(for folders: [String], exists: (String) -> Bool) -> [String]
      /// True when a change at `path` can change the scripts found in `folders`: the folder itself, or inside it,
      /// with no hidden component and at most `maxDepth + 1` components below the folder.
      public static func isRelevant(_ path: String, folders: [String], maxDepth: Int = 3) -> Bool
  }
  ```

- [ ] **Step 1: Write the failing tests:**
  - `` `only script-relevant paths trigger a reload` `` (folders `["/tmp/main", "/x/extra"]`):
    - relevant: `/tmp/main`, `/tmp/main/a.sh`, `/tmp/main/a/b/c/d.sh`, `/x/extra/tool.sh`
    - not relevant: `/tmp/main/a/b/c/d/e.sh`, `/tmp/main/.git/index`, `/tmp/main/sub/.hidden.sh`, `/tmp/mainly/a.sh`, `/tmp/Notes/n.md`
  - `` `a missing folder is watched through its parent` ``: with `exists` true only for `/tmp` and `/x/extra`, `watchPaths(["/tmp/main", "/x/extra"]) == ["/tmp", "/x/extra"]`. When neither the folder nor its parent exists, the folder is skipped.
- [ ] **Step 2: Run** `swift test --filter ScriptShortcutTests`. Expected: failures.
- [ ] **Step 3: Implement the app side.**
  - The watcher uses `watchPaths` and creates the stream with `kFSEventStreamCreateFlagUseCFTypes | kFSEventStreamCreateFlagFileEvents`.
  - The callback reads the paths (`CFArray` of `CFString`) and calls `onChange` only when one `isRelevant` for the folders.
  - Re-watch keys on the watch paths. When a missing folder appears, the library reload re-watches the folder itself.
- [ ] **Step 4: Run** `make test`. Expected: all pass.
- [ ] **Step 5: UI check** (test folders, log stream):
  - Rename the test `Scripts` folder away and relaunch. Create a file in `<root>/Notes` → no script reload (the hotkey log has no new lines, and `search.rebuild` is not observable, so add a `.debug` log "script folders changed" in the watcher and stream at debug level).
  - Rename `Scripts` back → the shortcuts of its scripts register within 3 s.
  - Touch `Scripts/.git/x` → no reload line.
  - App back on real data.
- [ ] **Step 6: Commit** `Watch missing script folders and ignore noise`.

# Tahap 18 (Theme Follows the System, Deferred Fixes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- DOT's windows follow macOS's light/dark switch live when Appearance is "System".
- Fix the tahap-16/17 minors.

**Architecture:**
- **Core:**
  - `AppleScriptEnd`: `.timedOut` and cleaner messages
  - `SystemCommand`: Empty Trash timeout; aliases trimmed
  - `SettingsData`: per-entry lenient tones; `ownSkinToneCount`
- **App:**
  - `ThemeController` observes `NSApp.effectiveAppearance` and resolves the System tint for it
  - `SystemCommandRunner` serializes AppleScript runs
  - the emoji ⌘T notice

**Tech Stack:** Swift 6.4, SwiftPM, AppKit/SwiftUI, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-18-design.md`.

## Global Constraints
- Same as tahap 17. No new permissions.
- The theme UI check switches the Mac's appearance with DOT's Toggle Dark Mode and switches it back.
- Every other UI check uses the test folders, dry run, and guarded keys.

## Review Focus
1. **System mode follows a live switch.** Dark → Light changes an open or reopened panel's glass to light without a relaunch, and back. Test: Task 2 UI check (RED first).
2. **Forced modes ignore the system.** With Appearance = Dark, switching macOS to Light keeps DOT dark. Test: Task 2 UI check.
3. **One bad tone value drops only itself.** Test: Task 1 `` `per-emoji tones load leniently` `` (mixed map).
4. **-1712 is not a failure.** Test: Task 1 `` `osascript endings are classified` ``.
5. **Two quick dark-mode toggles end where they started.** Runs are serialized. Test: Task 2 UI check (two dry-run lines in order, and the code path).

# Tahap 3 (Themes, Script Commands, Auto-expand, iCloud Sync) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the following to DOT Launcher:
- a Settings window backed by `settings.json`
- themes
- Raycast-compatible script commands
- snippet auto-expand
- opt-in iCloud Drive storage with rotating clipboard backups

**Architecture:**
- Testable logic goes in `DOTLauncherCore`:
  - settings file
  - theme model
  - script metadata parser and scanner
  - ANSI stripper
  - keyword expander
  - iCloud placeholder names
  - folder migration
  - backup rotation
  - SQLite backup/restore
- The app target owns the glue:
  - Settings window
  - theme application
  - Process-based script runner, HUD, panel modes
  - CGEventTap keystroke monitor
  - `SyncController`, which switches the active data folder
- All file-based data (snippets, notes, scripts, `settings.json`) lives under a **file data root** that is either local or iCloud. SQLite always stays under the **local root**.

**Tech Stack:** Swift 6.4 (Swift 6 mode), SwiftPM, AppKit + SwiftUI, SQLite3, CoreGraphics event taps, Foundation `Process`, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-3-design.md`. Read it first. `HANDOFF.md` describes the existing app, and `docs/superpowers/plans/2026-11-09-tahap-2-ledger.md` holds earlier rulings.

## Global Constraints

- **Toolchain**
  - `.macOS(.v27)`, Swift 6 mode, Command Line Tools only.
  - No `@State` (SwiftUI macro plugin missing). Use `@Observable` models and `@Bindable`.
  - No `#Preview`, no SwiftData, no XCTest, no external dependencies.
- **Isolation**
  - `DOTLauncherCore` imports no AppKit or SwiftUI.
  - The app target is `defaultIsolation(MainActor.self)`.
- **iCloud is opt-in**
  - With "Store data in iCloud Drive" off (the default), DOT must never read or write the iCloud folder.
  - The one exception is the user-pressed "Delete iCloud backups".
- **SQLite never lives in iCloud**
  - `clipboard.sqlite` and `launcher.sqlite` always stay in the local root.
- **Moving data**
  - Copy, verify, then delete.
  - Never overwrite: on a name clash keep both, giving the incoming file a suffix.
- **Test isolation**
  - Automated tests and UI checks use the override folders (`DOTDataRootOverride`, `DOTiCloudRootOverride`), never Pace's real data or real iCloud.
  - A real-iCloud check happens only with Pace's explicit consent, after a backup.
- **Panels and logging**
  - Panels stay non-activating, and the previous app stays frontmost.
  - Never log user content above `.debug`.
- **Workflow**
  - Run only via `make run`.
  - Verify UI with `osascript` System Events plus screenshots into the scratchpad.
  - Restore any window you move.
  - Tell Pace when his clipboard was overwritten.
  - Commit per task. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Interrupted migration.** If the app quits or crashes halfway through moving folders to or from iCloud, no file may be lost. Re-running the migration completes it. Covered in Task 11 test `` `resumes a half-finished migration without losing files` ``.
2. **Auto-expand feedback loop.** The backspaces and ⌘V that DOT posts must not be read back as typing and re-trigger. A keyword that is a suffix or prefix of another (`;a` vs `;addr`) must expand the right one. Covered in Task 9 tests and Task 10 step 4.
3. **Runaway scripts.** A script that never exits, or prints megabytes, must not hang or bloat DOT. Esc terminates it, and output is capped at 1 MB with a "…output truncated" line. Covered in Task 7 step 3.
4. **Awkward script input and output.** Arguments with spaces, quotes or `$` are passed as argv, never through a shell. Non-UTF-8 output is decoded lossily. Covered in Task 8 step 3.
5. **Evicted iCloud files.** With "Optimize Mac Storage", notes and snippets replaced by `.NAME.icloud` placeholders stay listed as "Downloading…" and are never silently dropped. Covered in Task 11 tests and Task 12 step 4.

  - **Turning off**: the reverse move, and backups stop. The iCloud backups stay, and the UI says so.
  - **When off**: no code path touches `iCloudRoot`. Keep a single `guard isEnabled` at the entry of every iCloud operation.
  - **Backups**:
    - Timing: at launch when the last backup is more than 6 h old, a 6 h timer, and in `applicationWillTerminate`.
    - Only when enabled, "Include clipboard history" is on, and no restore choice is pending.
    - Prune to 5.
  - **Restore**: a double-press confirm. Back up the local DB to `<localRoot>/clipboard-before-restore.sqlite`, then `ClipboardStore.restore`.
  - **Placeholders**: call `FileManager.startDownloadingUbiquitousItem(at:)`. The UI lists them as "Downloading…".

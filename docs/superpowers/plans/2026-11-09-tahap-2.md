# Tahap 2 (Snippets, Notes, AI Chat, Translator) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a translator, an on-device AI chat with an Indonesian translation bridge, launcher snippets, and a floating Markdown notes window to DOT Launcher. This sits on top of shared foundations: an Edit menu, secondary actions, a temporary-paste helper, and hiding the menu bar icon.

**Architecture:**
- Pure logic goes in `DOTLauncherCore` with Swift Testing TDD: language direction, Markdown segmenting and highlighting, the snippet and note file stores, the snippet expander, and press confirmation.
- AppKit, SwiftUI, Translation, and FoundationModels glue goes in the `DOTLauncher` app target.
- The launcher panel gains new modes (`.translate`, `.ai`, `.snippets`, `.notes`) driven by per-mode handlers.
- Notes and the snippet editor live in their own non-activating floating panels.

**Tech Stack:** Swift 6.4 (Swift 6 mode), SwiftPM, AppKit + SwiftUI, Translation, FoundationModels, NaturalLanguage, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-09-tahap-2-design.md`. Read it first. `HANDOFF.md` describes the existing app.

## Global Constraints

- Target `.macOS(.v27)`, `swift-tools-version: 6.4`, Swift 6 language mode. Only Command Line Tools are installed: no `#Preview`, no SwiftData, no XCTest.
- Tests use `import Testing`. The test target already carries the TestingMacros `-plugin-path` flag.
- Zero external dependencies.
- `DOTLauncherCore` must not import AppKit or SwiftUI. Allowed: Foundation, CoreGraphics, SQLite3, CryptoKit, NaturalLanguage.
- The app target uses `defaultIsolation(MainActor.self)` plus `NonisolatedNonsendingByDefault` and `InferIsolatedConformances`.
- Everything stays on the device. User data lives in `~/Library/Application Support/DOT Launcher/` (`AppPaths.supportDirectory`):
  - Snippets: `Snippets/<UUID>.json`
  - Notes: `Notes/<UUID>.md`
- Panels never call `NSApp.activate`. The previously frontmost app stays frontmost (`PanelController.targetApp`).
- Delete is **⌃X**, with a double-press confirmation within 3 s. ⌘⌫ keeps its text-editing meaning.
- Paste of snippet, AI, or translation output is temporary:
  - snapshot the pasteboard, write, ⌘V, then restore after 500 ms
  - not recorded in clipboard history
  - "Copy" is permanent and is recorded
- Never log user content at info level or above. Use `.debug` (not persisted) if needed.
- Run the app only via `make run`. Never use `swift run`.
- UI verification is automated with `osascript` System Events plus `screencapture -x` into the scratchpad. Rules for that:
  - Use a throwaway TextEdit document or Calculator as the target app.
  - Restore any window you move.
  - Don't touch full-screen media windows.
  - Tell Pace when his clipboard was overwritten.
- Commit at the end of each task. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Stale async results.** While typing fast in Translate mode, a slow translation of an older query must never overwrite the result for the newer one. Covered in Task 7, step 6.
2. **Emoji or combining characters before Markdown syntax.** Highlight ranges must land on the right characters (UTF-16 offsets). Covered in Task 13, test `` `ranges are UTF-16 offsets` ``.
3. **Foreign files in the Snippets/Notes folders.** `.DS_Store`, iCloud conflict copies, non-UTF-8 or corrupt JSON must be skipped, never crash, and never be listed. Covered in Task 9 and Task 12 tests.
4. **Non-text clipboard during a temporary paste.** The restore must bring back the original non-text data, such as a copied Finder file, not only plain text. Covered in Task 3, step 3.
5. **Missing language pair or unavailable model.** Translate and AI show a clear message and never hang in "Translating…" or "Thinking…". Covered in Task 6 (route tests), Task 7 step 6, and Task 8 step 7.

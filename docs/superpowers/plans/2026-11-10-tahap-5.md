**Goal:** Unit and currency conversion in the calculator row; global shortcuts for built-in commands; clipboard history retention and Clear History; the testable tahap-4 minors fixed.

**Tech Stack:** Swift 6.4, SwiftPM, AppKit + SwiftUI, Foundation `Measurement`, URLSession, SQLite3, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-5-design.md`. Read it first, plus `HANDOFF.md` and `docs/superpowers/plans/2026-11-10-tahap-4-ledger.md` (the minors this stage picks up).

## Global Constraints
- **Toolchain:** `.macOS(.v27)`, Swift 6, CLT only. No `@State`, `#Preview`, SwiftData, XCTest, or external dependencies. Core imports no AppKit/SwiftUI.
- **Network:**
  - The only network call is `GET https://open.er-api.com/v6/latest/USD`.
  - It runs only while a currency conversion is shown and the cache is missing or older than 12 h.
  - At most one request is in flight.
- **Local only:** `exchange-rates.json`, the SQLite files and `Clipboard Images/` live in `AppPaths.localRoot`, never iCloud.
- **Logging:** never log queries, clip text or chat text above `.debug`.
- **Test isolation:**
  - UI checks use `DOTDataRootOverride` → scratchpad folder.
  - Snapshot and restore Pace's clipboard (pbtool) around any check that writes to it.
  - Put the app back on real data after each UI check.
  - Never press a DOT-moved shortcut over Finder.
- **Workflow:** `make run` only. System Events + screenshots. Commit per task, with messages ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **Ambiguous unit words.**
   - `10 in in cm` must convert inches.
   - `1 m to ft` means metres. `cup` is volume, not CUP.
   - `5 min to s` means minutes, not a currency.
   - Test: Task 1 `` `ambiguous words resolve to units` ``.
2. **Stale or missing rates.**
   - Offline with a 10-day-old cache: show the result and say the rates may be outdated.
   - No cache and offline: one "unavailable" row, never a crash or a hung row.
   - Test: Task 2 `` `rates older than a week are marked outdated` `` + Task 3 step 4.
3. **Locale formatting.** Grouping `.` and decimal `,` for en_ID must never be mixed up in the copied value: the copy has no grouping. Test: Task 1 `` `copied value has no grouping` ``.
4. **Retention never touches pinned clips**, and image files go with their rows. Test: Task 4 `` `pruning keeps pinned clips and removes image files` ``.
5. **Command shortcuts never steal standard app shortcuts** (⌘C, ⌘V…). Test: Task 6 `` `standard app shortcuts are refused` ``.

  ```swift
  public struct MeasureUnit: Sendable, Hashable { public let symbol: String; public let category: Category; public enum Category: Sendable { case length, mass, temperature, volume, area, speed, duration, data } }
  public enum ConversionTarget: Sendable, Equatable { case unit(MeasureUnit); case currency(String) }
  public struct Conversion: Sendable, Equatable { public let amount: Double; public let from: ConversionTarget; public let to: ConversionTarget? }
  public enum Converter {
      /// nil when the input is not a conversion.
      public static func parse(_ input: String) -> Conversion?
      /// Unit to unit; nil for currencies or mismatched categories.
      public static func convertUnits(_ conversion: Conversion) -> Double?
  }
  public enum ConversionFormat {
      public static func display(_ value: Double, maxFractionDigits: Int?, significantDigits: Int?, locale: Locale) -> String   // grouped
      public static func copy(_ value: Double, maxFractionDigits: Int?, significantDigits: Int?, locale: Locale) -> String      // no grouping, locale decimal
  }
  ```
  Currency words are parsed in Task 2. Task 1's parser returns `.currency(code)` only for 3-letter codes passed through `Converter.isCurrencyCode`, which Task 2 replaces (set it up as `static var currencyLookup: (String) -> String?` defaulting to nil).

- [ ] **Step 1: Write the failing tests:**
  - `` `converts length, mass and data` ``: `10 km to mi` ≈ 6.21371; `1 lb in kg` ≈ 0.453592; `1 GiB to MB` ≈ 1073.741824; `2*5 km to m` = 10000; `10km to mi` (no space) ≈ 6.21371.
  - `` `converts temperature with offsets` ``: `100 c to f` = 212; `32 °F to C` = 0; `0 k to c` ≈ −273.15.
  - `` `ambiguous words resolve to units` ``: `10 in in cm` = 25.4; `1 m to ft` ≈ 3.28084; `1 cup to ml` ≈ 236.588; `5 min to s` = 300.
  - `` `long names and plurals are accepted` ``: `3 meters to feet`, `2 pounds = kg`, `1 kilometer ke m`.
  - `` `speed and area units` ``: `100 km/h to mph` ≈ 62.1371; `1 ha to m2` = 10000.
  - `` `different categories give no result` ``: `parse("10 km to kg")` is non-nil but `convertUnits` returns nil.
  - `` `plain text and calculations are not conversions` ``: `parse("2+2")`, `parse("hello world")`, `parse("km to mi")` (no amount) → nil.
  - `` `display uses significant digits and locale grouping` ``: `display(6213.7119, maxFractionDigits: nil, significantDigits: 6, locale: en_ID)` == "6.213,71".
  - `` `copied value has no grouping` ``: `copy(6213.7119, …, en_ID)` == "6213,71"; `copy(1807700, maxFractionDigits: 2, significantDigits: nil, en_US)` == "1807700".

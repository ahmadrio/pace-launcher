# Tahap 25 (Every Unicode 17 Emoji) Implementation Plan

> Executed inline (superpowers:executing-plans style) in the session that wrote it; steps are checked as done.

**Goal:** The emoji picker lists every RGI emoji of Unicode 17 (1914 without skin tones), including ZWJ sequences, keycaps, ©️ ®️ and subdivision flags, with skin tones where Unicode defines them.

**Architecture:** Single code points stay generated from Swift's Unicode properties. A generator turns Unicode's `emoji-test.txt` into a string table of sequences (Core) and a full list for tests. `EmojiCatalog` merges the sequences into its order and tones them from their medium-tone template.

**Tech Stack:** Swift 6.4, Swift Testing, CoreText (generator only).

**Spec:** `docs/superpowers/specs/2026-11-12-tahap-25-design.md`.

## Global Constraints
- Ids, names, order and keywords of existing emoji do not change (usage and own tones are keyed by character).
- Data version 17.0. The generator refuses emoji Apple Color Emoji cannot draw at one emoji's width.
- UI checks run on test data folders (`PACEDataRootOverride`, `PACEiCloudRootOverride`), typing only after a TextEdit-frontmost and panel-showing check. Afterwards the test app is removed, the test keys deleted, and `/Applications/PACE Launcher.app` reopened.
- No push, tag or release without Pace's yes.

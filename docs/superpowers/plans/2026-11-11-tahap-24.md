# Tahap 24 (Ready to Publish) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the repository ready to become public (README, LICENSE, PRIVACY, release notes, fixed release scripts, a clean secret scan), so publishing is one confirmed step.

**Architecture:** Docs at the repo root and in `docs/`; shell fixes in `scripts/`; no app code changes. Publishing itself (repo, push, tag, release) happens after the merge and only on Pace's yes.

**Tech Stack:** Markdown, bash, `gh`, `gitleaks`, `screencapture`.

**Spec:** `docs/superpowers/specs/2026-11-11-tahap-24-design.md`.

## Global Constraints
- Repo `ahmadrio/pace-launcher`, tag `v1.0.0`, release files `PACE-Launcher-1.0.0.dmg` + `.dmg.sha256`.
- **No `gh repo create`, `git push`, tag push or `gh release create` in this plan.** Those come after the merge, on Pace's explicit yes.
- **Never run `scripts/make-signing-identity.sh`** (a wrong check would add a second identity to Pace's keychain). Never print or copy the private key.
- User docs in English; HANDOFF in Indonesian. The Raycast name is never used to market PACE.
- Screenshots come from test data folders (`t6/env.sh on`); afterwards the app is quit and removed from `~/Applications`, and the test keys are deleted. Typing only through `t12/guardtype`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **A dirty or non-git tree packaged as a real release.** Expected: outside git the script refuses; with `PACE_ALLOW_DIRTY=1` the files are named `…-dirty.dmg`. Test: Task 1 Step 2.
2. **A check failing after the DMG was written.** Expected: no file with the final name remains. Test: Task 1 Step 4.
3. **README or PRIVACY claims that the code does not back.** Expected: every network call, storage place and permission named matches the code. Test: Task 2 Step 3 cross-check list.
4. **Secrets anywhere in history.** Expected: gitleaks finds nothing; the personal-data list is reported. Test: Task 4.
5. **Images leaking personal data.** Expected: screenshots show test data only. Test: Task 3 Step 3 visual check.

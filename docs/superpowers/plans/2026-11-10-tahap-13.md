# Tahap 13 (Deferred Fixes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The tahap-12 deferred minors plus a sign when a missing script's shortcut is pressed.

**Architecture:**
- Core:
  - `PressConfirmation` gains a notice-aware press and `isArmed`
  - `EmojiSkinTone.default`
  - `EmojiCatalog.toned` skips non-RGI bases
- App:
  - Log Out uses the Core gate and clears its notice when the arm ends
  - missing script shortcuts are registered and show the existing "Script not found" HUD

**Tech Stack:** Swift 6.4, SwiftPM, AppKit, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-13-design.md`.

## Global Constraints
- Same as tahap 12. No new permissions.
- UI checks use the test folders, the focus guards, clipboard snapshots, and `DOTSystemCommandDryRun` for system commands.

## Review Focus
1. **A stale arm never logs out.** When the notice is gone (typing, moving, reopening, 3 s), ↩ only re-arms. Test: Task 1 `` `a second press counts only while its notice shows` `` + Task 2 UI check.
2. **The notice and the arm end together.** The footer clears 3 s after the first ↩. Test: Task 2 UI check.
3. **Old settings still load.** `"emojiSkinTone": "none"` decodes to `.default` and is written back as `"none"`. Test: Task 1 `` `skin tone loads leniently` ``.
4. **No broken toned emoji.** Every catalog emoji, toned, is either unchanged or exactly base + modifier, and 👪 👯 🤼 stay unchanged. Test: Task 1 `` `toned emoji are base plus modifier or unchanged` ``.
5. **A missing script's shortcut speaks up and recovers.** Pressing it shows "Script not found: <file>"; once the file exists, the same press runs it. Test: Task 2 UI check.

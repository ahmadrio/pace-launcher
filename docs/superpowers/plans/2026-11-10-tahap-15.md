# Tahap 15 (Reliable Script Form, Tested Confirmations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Typed-ahead text lands whole in the script form's first field, the form refocuses when re-prepared, and `ConfirmationPrompt` moves to Core with tests.

**Architecture:**
- Core: `Search/ConfirmationPrompt` (moved from the app), `@MainActor`, with an injected clock (`now`) and `sleep`.
- App:
  - `ScriptArgumentForm.preparation` counter
  - the form view gets `.id(preparation)` at the call site
  - after focusing, the form asks for the search field's text (an `onFocused` closure), which `LauncherModel.moveTypedAhead()` inserts into the focused field editor

**Tech Stack:** Swift 6.4, SwiftPM, AppKit/SwiftUI, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-15-design.md`.

## Global Constraints
- Same as tahap 14. No new permissions.
- UI checks use the test folders, the focus guards, clipboard snapshots, and test scripts that only touch scratchpad markers.

### Task 1: ConfirmationPrompt in Core

**Files:**
- Create: `Sources/DOTLauncherCore/Search/ConfirmationPrompt.swift`
- Delete: `Sources/DOTLauncher/UI/ConfirmationPrompt.swift`
- Test: `Tests/DOTLauncherCoreTests/ConfirmationPromptTests.swift`

**Interfaces:**
- Produces:
  ```swift
  @MainActor public final class ConfirmationPrompt {
      public init(window: TimeInterval = 3, now: @escaping @MainActor () -> Date = { .now },
                  sleep: @escaping @MainActor (TimeInterval) async -> Void = { try? await Task.sleep(for: .seconds($0)) })
      public var window: TimeInterval { get }
      @discardableResult  // the hiding task, for tests
      public func press(_ id: String, isShown: @escaping @MainActor () -> Bool, show: () -> Void,
                        hide: @escaping @MainActor () -> Void) -> Bool
      var pendingHide: Task<Void, Never>? { get }   // internal, for @testable tests
      public func reset()
  }
  ```
  The behavior is the tahap-14 app version: sleep `window + 0.1`, then poll every 0.2 s while armed, then `hide()` if `isShown()`.
- [ ] **Step 1: Write the failing tests** (a fake clock whose `sleep` advances `now`, @MainActor):
  - `` `a stale press only shows the prompt again` ``: press (shown) → false. With `isShown` now false, press → false, and `show` was called twice.
  - `` `a confirmed press hides its prompt` ``: press, press → true, and `hide` was called once.
  - `` `the prompt goes when the first press ends` ``: press, await `pendingHide`. Then `hide` was called once, and the fake time is ≥ window.
  - `` `a newer press keeps the prompt up` ``:
    1. Press at t0.
    2. Mark the prompt hidden.
    3. At t0+1 press again (re-arms, shows).
    4. Await the first task.
    5. Expect `hide` called only after the fake time ≥ t0+4.
  - `` `another prompt is never hidden` ``: press; `isShown` becomes false (replaced); await → `hide` never called.
- [ ] **Step 2: Run** `swift test --filter ConfirmationPromptTests`. Expected: failure (type missing).
- [ ] **Step 3: Implement.** Move the class into Core and delete the app copy. App call sites stay the same, because `import DOTLauncherCore` is already there.
- [ ] **Step 4: Run** `make test`. Expected: all pass.
- [ ] **Step 5: Commit** `Move ConfirmationPrompt to Core with tests`.

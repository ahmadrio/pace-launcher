# Tahap 17 (Restart, Shut Down, Empty Trash, Dark Mode) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four system commands that use Automation (Apple Events through `osascript`), with confirmations, permission messages and a dry run.

**Architecture:**
- Core:
  - `SystemCommand` gains four cases, an `.appleScript(source:target:)` action and `confirmationNotice`
  - `AppleScriptEnd` classifies the osascript result
  - `CommandShortcut.toggleDarkMode`
- App:
  - `SystemCommandRunner` runs osascript and reports the end
  - AppDelegate shares one `ConfirmationPrompt` across the confirming commands and shows HUDs
  - Info.plist gets `NSAppleEventsUsageDescription`

**Tech Stack:** Swift 6.4, SwiftPM, AppKit, Foundation `Process`, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-17-design.md`.

## Global Constraints
- Same as tahap 16.
- The only new permission is Automation. No Full Disk Access, and nothing touches `~/.Trash` directly.
- UI checks never run these commands for real: set `DOTSystemCommandDryRun` first and delete it afterwards. Use the per-key guarded typing tools, and no multi-key AppleScripts with delays.

## Review Focus
1. **One stray ↩ never restarts, shuts down or empties the Trash.** One ↩ only shows the notice; a stale arm only re-arms. Test: Task 2 UI check (dry run).
2. **Dry run is total.** No osascript is started for any of the four. Test: Task 2 UI check (log lines only).
3. **A denied permission is explained.** -1743 maps to "not permitted" with the target app's name. Test: Task 1 `` `osascript endings are classified` ``.
4. **Cancel in macOS's dialog is quiet.** -128 maps to canceled. Test: Task 1.
5. **Without the usage description, macOS refuses silently.** The key must be present. Test: Task 1 `` `the app explains its Apple Events` `` (reads `Resources/Info.plist`).

**Interfaces:**
- Produces:
  ```swift
  // SystemCommand: + restart, shutDown = "shut-down", emptyTrash = "empty-trash", toggleDarkMode = "toggle-dark-mode"
  // Action: + case appleScript(source: String, target: String)   // target: "loginwindow", "Finder", "System Events"
  public var confirmationNotice: String?   // "Press ↩ again to log out" / "to restart" / "to shut down" / "to empty the Trash"; nil otherwise
  // needsConfirmation == (confirmationNotice != nil)
  public enum AppleScriptEnd: Equatable, Sendable {
      case done, notPermitted, canceled, failed(String)
      public init(status: Int32, errorOutput: String)   // 0 → done; "(-1743)" → notPermitted; "(-128)" → canceled; else failed(last line, trimmed, at most 120 chars)
  }
  // CommandShortcut: + toggleDarkMode = "toggle-dark-mode" ("Toggle Dark Mode")
  ```

### Task 2: App

**Files:**
- Modify: `Sources/DOTLauncher/System/SystemCommandRunner.swift`, `Sources/DOTLauncher/App/AppDelegate.swift`

**Interfaces:**
- Produces: `SystemCommandRunner.run(_:onFocusStuck:onScriptEnd: @escaping @MainActor (AppleScriptEnd) -> Void = { _ in }) -> Bool`.

- [ ] **Step 1: Implement.**
  - **Runner, `.appleScript`:**
    - Start `/usr/bin/osascript -e <source>` with a stderr pipe.
    - When it ends, hop to the main actor and call `onScriptEnd(AppleScriptEnd(status:errorOutput:))`.
    - A dry run returns before this point, as it does now.
  - **AppDelegate:**
    - `logOutPrompt` becomes `systemPrompt`, used for every command with a `confirmationNotice`; the notice is the command's own.
    - `actionTitle` is the title for confirming commands, otherwise "Run".
    - **`onScriptEnd`:**
      - `.notPermitted` → HUD "Allow DOT Launcher to control <target> in Privacy & Security › Automation." and open `x-apple.systempreferences:com.apple.preference.security?Privacy_Automation`.
      - `.canceled` → nothing.
      - `.failed(m)` → HUD "Could not <title lowercased>: m".
      - `.done` → for Empty Trash, HUD "Emptied the Trash."
- [ ] **Step 2: Run** `make test`. Expected: all pass. Also check `plutil -extract NSAppleEventsUsageDescription raw` on the installed app's Info.plist.
- [ ] **Step 3: UI check** (test folders + dry run; log stream on "system command"):
  - **Restart:** `restart` ↩ → notice "Press ↩ again to restart" and no log line; ↩ → "system command restart (dry run)".
  - **Shut Down:** `shut down`, the same with "shut down".
  - **Empty Trash:** `empty trash`, the same with "empty the Trash". Typing a letter and deleting it between the presses → only the notice.
  - **Dark Mode:** `dark mode` ↩ → a dry-run line on the first press.
  - **Shortcuts:** Settings › Shortcuts lists Toggle Dark Mode under Commands.
  - **No osascript runs:** `pgrep -f "osascript -e"` stays empty throughout.
  - **Cleanup:** remove the flag, and put the app back on real data.

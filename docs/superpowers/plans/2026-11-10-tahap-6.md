> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

## Review Focus
1. **Shorthand never changes a unit.** `10k to c` stays kelvin, `1 m to ft` stays metres, `10kg to lb` stays kilograms, `1jt to kg` is not a conversion. Test: Task 1 `` `units win over shorthand` ``.
2. **Same title, same file name.** Two scripts titled "Hello" (or two `hello.sh` in different folders) get separate shortcuts that both register and both show in Settings. Tests: Task 4 `` `same-named files in different folders get different keys` `` and `` `duplicate titles get their folder as detail` ``. Task 5 step 4 checks both register.
3. **A missing script keeps its shortcut.** The shortcut stays in settings.json, is not registered, shows as "Not found on this Mac", and works again when the file returns. Test: Task 4 `` `rows keep shortcuts of missing scripts` `` and Task 5 step 4.
4. **Hand-edited settings.json cannot take ⌘V or a bare letter.** Test: Task 3 `` `unusable saved combos fall back` ``.
5. **A confirmation script never runs on a single press.** Test: Task 4 `` `confirmation scripts ask before running` ``.

# Tahap 19 (Tahap-18 Deferred Fixes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- An "Appearance Settings" command.
- One run at a time per system command: Toggle Dark Mode queues, while the other commands ignore a duplicate.
- Honest timeout messages, and a tested run queue.
- Check that Notes and the snippet editor follow a live appearance switch.

**Architecture:**
- **Core:**
  - `System/ScriptRunQueue` (pure, generic over key and job)
  - `SystemCommand.queuesRepeatRuns`
  - `AppleScriptEnd.alreadyRunning`
- **App:**
  - the runner uses the queue and logs start and end
  - AppDelegate HUDs
  - `CommandCatalog` gets the Appearance command

**Tech Stack:** Swift 6.4, SwiftPM, AppKit, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-19-design.md`.

## Global Constraints
- Same as tahap 18. No new permissions.
- UI checks:
  - Run on the test folders.
  - Use a dry run, except for the appearance switch, which uses DOT's Toggle Dark Mode and is switched back.
  - Send keys only through the guarded tools.
  - Never run Restart, Shut Down or Empty Trash for real.

## Review Focus
1. **Duplicate Restart is ignored, not queued.** Test: Task 1 `` `a busy command drops repeats unless it queues them` ``.
2. **Toggle Dark Mode still queues in order.** Test: Task 1 `` `queued runs start in order after each finish` ``.
3. **A run that fails to start frees its command.** Test: Task 1 (`finish` after a failed start).
4. **`tema` opens Appearance.** Test: Task 2 UI check (Settings shows the Appearance section).
5. **Notes and the snippet editor follow a live switch.** Test: Task 2 UI check (luminance in Dark vs Light).

### Task 1: Core

**Files:**
- Create: `Sources/DOTLauncherCore/System/ScriptRunQueue.swift`
- Modify: `SystemCommand.swift`, `AppleScriptEnd.swift`
- Test: `Tests/DOTLauncherCoreTests/ScriptRunQueueTests.swift`, `SystemCommandTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public struct ScriptRunQueue<Key: Hashable, Job> {
      public enum Decision { case start(Job), queued, dropped }
      public init()
      public mutating func submit(_ job: Job, for key: Key, queueIfBusy: Bool) -> Decision
      public mutating func finish(_ key: Key) -> Job?   // the next job to start (still marked running), or nil (idle)
      public func isRunning(_ key: Key) -> Bool
  }
  // SystemCommand: public var queuesRepeatRuns: Bool  // true only for .toggleDarkMode
  // AppleScriptEnd: + case alreadyRunning   // not started: the same command is still running
  ```
- [ ] **Step 1: Write the failing tests:**
  - `` `queued runs start in order after each finish` ``:
    - `submit(a1, "dark", queueIfBusy: true)` → `.start(a1)`
    - `submit(a2, …)` → `.queued`; `submit(a3, …)` → `.queued`
    - `finish("dark")` → a2; `finish` → a3; `finish` → nil
    - `isRunning("dark")` → false
  - `` `a busy command drops repeats unless it queues them` ``:
    - `submit(r1, "restart", false)` → `.start`; `submit(r2, "restart", false)` → `.dropped`
    - another key starts at once
    - `finish("restart")` → nil, and then a new `submit` → `.start`
  - `` `system commands that queue repeats` ``: `SystemCommand.allCases.filter(\.queuesRepeatRuns) == [.toggleDarkMode]`.
- [ ] **Step 2: Run** the filters. Expected: failures.
- [ ] **Step 3: Implement.**
- [ ] **Step 4: Run** `make test`. Expected: all pass.
- [ ] **Step 5: Commit** `Queue dark-mode runs and drop repeats of the others, in Core`.

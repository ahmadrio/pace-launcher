# Tahap 11 (System Commands, Deferred Fixes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lock Screen, Sleep, Sleep Displays, Start Screen Saver and Log Out commands, plus the tahap-10 deferred minors.

**Architecture:**
- Core:
  - `System/SystemCommand`: what each command does, as data
  - `CommandShortcut` cases for the four non-confirming commands
  - quicklink browser decoding
  - city-word filter in `TimeZoneNames`
- App:
  - `SystemCommandRunner` (keys via CGEvent, `pmset` via `Process`, Screen Saver via `NSWorkspace`), with a dry-run hook
  - catalog rows with a press-twice confirmation for Log Out
  - quicklink opener fallback

**Tech Stack:** Swift 6.4, SwiftPM, AppKit, CoreGraphics events, Swift Testing. Command Line Tools only.

**Spec:** `docs/superpowers/specs/2026-11-10-tahap-11-design.md`.

## Global Constraints
- Same as tahap 10.
- **No new permissions:** never send Apple Events, and never touch `~/.Trash`.
- **UI checks never run a system command for real:** set `defaults write com.pace.DOTLauncher DOTSystemCommandDryRun -bool true` first, and delete it afterwards.

## Review Focus
1. **Log Out needs two presses.** One ⏎ only shows "Press ↩ again to log out"; the second within 3 s runs it; a press after 3 s starts over. Test: Task 2 UI check (dry-run log).
2. **Dry run is total.** With the flag set, no key is posted, no `pmset` runs and no app opens. Test: Task 2 UI check (log only, Mac stays awake).
3. **Command shortcuts.** The four commands appear in Settings › Shortcuts › Commands; Log Out does not. Test: Task 1 `` `system commands that can have shortcuts` ``.
4. **Words after a time are not cities.** `5pm to wake` → nil, while `time in phoenix` still works. Test: Task 3.
5. **Empty browser.** `"browser": ""` behaves as the default browser. Test: Task 3.

  public enum SystemCommand: String, CaseIterable, Sendable {
      case lockScreen = "lock-screen", sleep, sleepDisplays = "sleep-displays", screenSaver = "screen-saver", logOut = "log-out"
      public enum Action: Equatable, Sendable {
          case keys(KeyCombo)                      // posted with CGEvent
          case process(path: String, arguments: [String])
          case openApp(path: String)
      }
      public var title: String       // "Lock Screen", "Sleep", "Sleep Displays", "Start Screen Saver", "Log Out"
      public var subtitle: String    // one line on what happens
      public var aliases: [String]   // lock/kunci, tidur, screensaver, logout/keluar
      public var symbol: String      // SF Symbol
      public var action: Action      // lock: ctrl+cmd+q; logOut: shift+cmd+q; sleep: pmset sleepnow;
                                     // sleepDisplays: pmset displaysleepnow; screenSaver: /System/Library/CoreServices/ScreenSaverEngine.app
      public var needsConfirmation: Bool   // logOut only
      public var needsAccessibility: Bool  // the .keys actions
  }
  // CommandShortcut: + lockScreen = "lock-screen", sleep, sleepDisplays = "sleep-displays", screenSaver = "screen-saver"

### Task 2: System commands in the launcher

**Files:**
- Create: `Sources/DOTLauncher/System/SystemCommandRunner.swift`
- Modify: `Sources/DOTLauncher/Commands/CommandCatalog.swift`, `Sources/DOTLauncher/App/AppDelegate.swift`

**Interfaces:**
- Produces: `SystemCommandRunner.run(_ command: SystemCommand) -> Bool` (false when Accessibility is missing for `.keys`). With `DOTSystemCommandDryRun` it logs `system command <raw> (dry run)` at `.info` and returns true.

- [ ] **Step 1: Implement.**
  - **Runner:**
    - `.keys`: convert `KeyCombo` carbon modifiers to `CGEventFlags`, then post key down/up to `.cghidEventTap` after 80 ms, so the panel orders out first.
    - `.process`: `Process`, fire and forget.
    - `.openApp`: `NSWorkspace.shared.openApplication(at:configuration:)`.
  - **Catalog** `systemCommands(run:)`:
    - one `LauncherCommand` per case, with id = raw value
    - `.run` for commands without confirmation
    - Log Out uses `.stay` with a `PressConfirmation` keyed "log-out": the first press sets `model.notice = "Press ↩ again to log out"`, the second calls `model.close()` and runs.
  - **Without Accessibility:** for `.keys`, `model.notice = "Allow Accessibility to lock or log out"` and `AccessibilityPermission.prompt()`.
- [ ] **Step 2: Run** `make test`. Expected: all pass.
- [ ] **Step 3: UI check** (test folders + dry run):
  - `lock` ⏎ → log "system command lock-screen (dry run)"; the screen stays unlocked.
  - `sleep` ⏎ and `screensaver` ⏎ → dry-run lines.
  - `log out` ⏎ once → notice "Press ↩ again to log out" and no log line; ⏎ again → the dry-run line. ⏎ once, wait 4 s, ⏎ → notice again, no line.
  - Settings › Shortcuts lists Lock Screen … Start Screen Saver under Commands.
  - Remove the dry-run flag, and put the app back on real data.
- [ ] **Step 4: Commit** `Add lock, sleep, screen saver and log out commands`.

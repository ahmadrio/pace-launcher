The first public release of PACE Launcher: a free, open-source launcher for macOS that works on your Mac.

**Requirements:** macOS 27 on Apple silicon.

## Install
1. Download `PACE-Launcher-1.0.0.dmg` and `PACE-Launcher-1.0.0.dmg.sha256` below.
2. Optional: check the download. In Terminal, in the folder holding both files (for example `cd ~/Downloads`), run `shasum -a 256 -c PACE-Launcher-1.0.0.dmg.sha256`; it should print `OK`.
3. Open the DMG and drag PACE Launcher to Applications.
4. PACE Launcher is not notarized by Apple. The first time, open it, click **Done**, then go to **System Settings › Privacy & Security** and click **Open Anyway**.

The full guide, including permissions, updating and uninstalling, is in [docs/INSTALL.md](https://github.com/ahmadrio/pace-launcher/blob/main/docs/INSTALL.md).

## What's in it
- **Launcher** on ⌥Space: apps, commands, quicklinks, snippets and script commands, ranked by what you use.
- **Calculator** with unit and currency conversion, number shorthands (`1jt`, `10k`), dates and time zones (`time in tokyo`, `days until 17 aug`).
- **Clipboard history** for text, rich text, files and images, with pins, search and paste as plain text.
- **Snippets** with placeholders, pasted from the launcher or expanded as you type.
- **Window snapping** (halves, quarters, maximize, restore) with ⌃⌥ shortcuts.
- **Notes**: floating Markdown notes with autosave.
- **Script commands** with arguments and several output modes.
- **AI chat and translation** that run on your Mac.
- **Emoji picker** with skin tones, **system commands** (lock, sleep, log out, restart, empty trash, dark mode), **themes**, **custom shortcuts**, and optional **iCloud sync**.
- A **welcome window** that explains each permission, and a daily **update check** you can turn off.

See [PRIVACY.md](https://github.com/ahmadrio/pace-launcher/blob/main/PRIVACY.md) for what PACE stores and its two internet connections.
